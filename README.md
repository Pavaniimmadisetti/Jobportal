# Job Portal Fullstack Application

This is a full-stack Job Portal web application developed using React.js, Node.js, Express, and MySQL. The application allows users to register, login, view available jobs, and apply for them. It provides a simple and efficient platform for managing job listings and applications.

## Features

- User Registration and Login
- View available job listings
- Apply for jobs
- Backend REST API integration
- MySQL database connectivity
- Fullstack architecture with React frontend and Node.js backend

## Tech Stack

Frontend:
- React.js
- Axios
- React Router DOM

Backend:
- Node.js
- Express.js

Database:
- MySQL
 job-portal-fullstack/
│
├── frontend/ # React frontend
├── backend/ # Node.js backend
└── database/ # MySQL schema


## How to Run

Backend:


cd backend
npm install
node server.js


Frontend:


cd frontend
npm install
npm start


Database:
Import `database/schema.sql` into MySQL.
